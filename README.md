# Bay Tahmin

Telefonda ana ekrana eklenebilen (PWA) futbol maç analizi ve bahis tahmini uygulaması.

- Veri: [API-Football](https://www.api-football.com/) (anahtar yalnızca kullanıcının cihazında saklanır)
- Analiz: puan durumu (ev/deplasman), son 6 maç formu, sakat/cezalı oyuncuların etkisi, bahis firması oranlarından marjı temizlenmiş piyasa olasılıkları, Poisson + Dixon-Coles skor modeli.

Tahminler istatistiksel modeldir, sonuç garantisi vermez.
